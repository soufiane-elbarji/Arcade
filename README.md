#### Arcade V.1
#### Video Demo:  [https://youtu.be/rFvinCrfBlA](https://youtu.be/rFvinCrfBlA)
#### Description:

**Arcade V.1** is a comprehensive web-based gaming platform designed with a retro neon aesthetic. Built using Python's Flask framework for the backend and vanilla JavaScript for the frontend, this application serves as a hub for classic arcade entertainment. The project emphasizes a seamless user experience, featuring a "Glassmorphism" design language with animated background lights and a responsive layout that adapts to laptop screens while enforcing a desktop-first experience for optimal gameplay control.

The core functionality revolves around a robust user system handled by a SQL database. Users can securely register and log in to track their progress. The application implements an Experience Point (EXP) system where every game played contributes to the user's total score via an API endpoint. This data persists to populate a competitive Global Leaderboard that displays the top players. Additionally, the system includes an exclusive Admin Panel—accessible only to the 'admin' user—that provides insights into registered users and site traffic.

The platform boasts a library of eight fully functional games, all implemented from scratch using HTML5 Canvas. These include **Snake** with adjustable difficulty settings; **Tic-Tac-Toe** featuring a Minimax-powered AI opponent; **2048** for puzzle lovers; **Breakout** and **Tetris** for classic arcade action; **Flappy Ball** utilizing physics-based movement; **Minesweeper** with multiple grid sizes; and a complex recreation of **Pac-Man** complete with distinct Ghost AI behaviors and map navigation.
